Deque Operations

1. Add head

Inserts a new element at the head.

2. Add tail

Appends a new element at the tail.

3. Remove Head

Removes and returns element from the Head.

4. Remove Tail

Removes and returns element from the tail.

5. Peek Head & Tail

Inspect values at both ends without removing.

6. Clear Deque

Empties all elements from the deque.
